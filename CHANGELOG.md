Initial experimental publication of the existing unofficial Infinity 4.2 / Android 17 ARM64 A/B images.

- Vanilla image: internal build date November 12, 2026.
- MindTheGapps image: internal build date November 13, 2026.
- Android security patch property: November 1, 2026; platform build ID `CP2A.260605.016`.
- TrebleDroid product integration, available VNDK compatibility snapshots, MediaTek/display adaptations, and Android 17 build fixes.
- Direct MindTheGapps `cinnamonbun` inheritance with the separate Pixel GMS tree excluded.
- Real Android virtualization implementation retained, with incompatible replacement stubs excluded.
- Documentation, checksums, image properties, source provenance, patch inputs, and reference source copies accompany the release.

Both image builds completed successfully. On-device testing remains unconfirmed. These existing images were not rebuilt or modified solely for publication.
